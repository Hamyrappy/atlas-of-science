# Атлас Науки — открытая инициатива

**Машиночитаемое представление научного знания.** Ведётся с 2025 года.

Страница инициативы: `index.html` (разворачивается на GitHub Pages).

## Зачем

Одну статью языковая модель прочитает и без всякой разметки. Восемьдесят тысяч работ одной области — уже нет: в контекст они не помещаются, а перечитывать корпус под каждый вопрос дорого, и каждый раз выходит другой ответ.

Атлас Науки читает корпус один раз и оставляет разметку: утверждения, вынутые из текста, приведённые к общим типам и связанные с дословным фрагментом источника. Дальше вопросы задают разметке, а не текстам.

```
L4  Карта области      портфель работ, дрейф тематик
L3  Тема               кластер связанных работ
L2  Документ           статья, отчёт, патент
L1  Карточка           Result · Method · Claim · Dataset
L0  Спан               дословный фрагмент источника
```

Правило, на котором всё держится: **нет провенанса — нет узла.**

## Направления

Работа разбита на направления. Они опираются на общий формат разметки, но не зависят друг от друга: направление можно вести, не дожидаясь остальных.

- **Онтология** — каркас типов и правила, по которым он растёт, в том числе автоматически под конкретную область
- **Извлечение и провенанс** — от текста к карточкам со ссылкой на дословный фрагмент
- **Доменная адаптация** — перенос в новую область: свой словарь при неизменном каркасе
- **Поиск для агентов** — разметка как слой поиска внутри исследовательских агентов
- **Интерпретаторы верхних уровней** — карты областей, динамика тематик, портфели работ
- **Консенсус и противоречия** — поддержка, противоречие, независимость свидетельств, воспроизводимость
- **Оценка и приёмка** — чем измеряется качество разметки и когда она считается готовой
- **Инфраструктура и данные** — хранение графа, воспроизводимая сборка, публикация в открытом доступе
